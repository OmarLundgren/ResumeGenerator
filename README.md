Title: AI Resumé generator

Description:

A full-stack ASP.NET Core application that transforms your GitHub profile into a high-impact professional résumé.

Key Features:

Secure Authentication: Implements GitHub OAuth 2.0 for seamless user login.

Dynamic Data Fetching: Integrates with the GitHub API to extract profile details and repository metrics.

AI Synthesis: Leverages the Google Gemini 3 Flash model to analyze project descriptions and star counts, generating structured Markdown résumés.

Harvard Standard Formatting: Automatically structures content following elite academic and industry standards.
